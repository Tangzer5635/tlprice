# Captures d écran

Depose ici trois captures nommees exactement :

- `solde.png`
- `calendrier.png`
- `controle.png`

Le README les affiche automatiquement dans un tableau a trois colonnes.

## Comment les prendre

Sur iPhone, bouton lateral + volume haut. Rogne la barre d etat si tu veux
un rendu plus propre : l heure et le pourcentage de batterie n apportent rien
et datent la capture.

Verifie avant de publier qu aucun montant reel n apparait. Le plus simple est
de saisir quelques operations plausibles dans un compte de test plutot que de
flouter apres coup — un floutage se retire parfois.
